## 팀 소개
**팀장**: 조영
- 총괄, 모각 페이지, 톡톡 페이지, 스페이서 랭크, 홈, 마이페이지

**팀원**: 정원형
- 회원가입, 아바타 수정, 캐치업

**팀원**: 손성민
- 회원가입 UI, 마이페이지 UI

## SFACE 프로젝트 개요
스나이퍼 팩토리의 교육생들을 위한 종합 커뮤니티 앱 입니다.

## 주요기능 
### **회원가입 및 로그인**
회원 가입 , 로그인 처리에 대한 기능 

### **톡톡**
교육생들 간의 실시간 커뮤니케이션을 가능하게 하는 댓글 기반 메신저 기능

### **모여서 각자 코딩 **
코딩 공부를 위한 학습자들의 참여형 게시판

### **랭크 시스템**
사용자의 학습 성취도에 따라 랭크를 부여하는 기능
